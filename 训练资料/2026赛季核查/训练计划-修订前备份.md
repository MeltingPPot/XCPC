# 2026 南京、南昌、长春命题组对点训练

> 起始日期：2026-09-25  
> 目标赛站：ICPC 南京、ICPC 南昌；CCPC 长春  
> 训练规模：每周 3 道重点题 + 1 场团队 VP；上课周不额外加量

| 目标 | 目前能确认的公开信息 | 训练依据 | 可信度 |

- [ ] `5%`：最近网络赛暴露出的个人问题

## 二、WHU×XDU 对点题单：南昌主线

### 风格判断

- 题目常先要求找到一个强等价转化，再接标准算法。
- 数学题不止纯数论，常把 `gcd/φ`、博弈、代数运算、构造与图论或数据结构组合。
- 中档题可写性强，但读题、证明和实现三项缺一不可。
- 2026 邀请赛官方预估梯度为 `A/I/B → D/F → C/H/J → L/G → K/E/M`，适合做完整团队训练。

### 整场训练

- [ ] [2026 ICPC 南昌邀请赛](https://codeforces.com/gym/106551) 五小时团队 VP
  - 前 30 分钟目标：识别 `A、I、B`，并让数学位读 `H、J、L`
  - 三小时目标：完成 `A、I、B、H、J` 中至少 4 题
  - 赛后只补 2 题：一道赛时应过题 + 一道数学核心题
- [ ] [2025 ICPC 南昌邀请赛](https://codeforces.com/gym/105911) 三小时选题训练
  - 不要求整场打满；重点读 `F、I、K、M`
  - 若整套已经做过，只限时重做 `I`，再从 `F/K/M` 中选一题

### 数学位必做

- [ ] `2026 H - BABA BOOEY`：限制取石博弈；从奇偶递归到异或和的 `lowbit`
  - 任务：不用 SG 函数，独立写出“除以 2”递归为何成立的证明
- [ ] `2026 J - Journey of GCD`：完全图最大瓶颈路、约数虚点、Kruskal 重构树
  - 任务：证明任意 gcd 边都能由约数中转点等价替代
- [ ] `2026 L - Little Z's Function`：欧拉函数乘法公式、支配对、扫描线
  - 任务：先从 `φ(ab)` 恒等式推到“固定约数 d 只保留最大的两个 φ 值”，再写实现
- [ ] `2026 C - Tourist`：`min-max` 半环矩阵快速幂
  - 任务：证明自定义矩阵乘法满足结合律；把它整理进数学算法笔记
- [ ] `2025 I - Dating Day`：组合计数、容斥与双指针
  - 任务：先手推计数式，再决定实现；禁止直接照代码

### 推荐提高

- [ ] `2026 F - One Touch Drawing`：传送点条件下的欧拉路等价转化
- [ ] `2026 K - Legacy Code`：乘法程序的指数矩阵、费马小定理与加速
- [ ] `2025 F - Caloric Difference`：贪心与数学结构
- [ ] `2025 K - Rotation`：旋转结构与构造

## 三、SUA 对点题单：南京主线

### 风格判断

- 难度梯度完整，签到题也可能依赖一个短而关键的性质。
- 中档题常是“先证明结构，再用贪心、DP、容斥、数据结构兑现”。
- 数学对象与图、字符串、几何、概率混合明显；不能只盯着题面像数论的题。
- 近两年南京站均存在大量通过数在 20～150 队之间的中档题，这正是团队拉开差距的位置。

### 整场训练

- [ ] [2025 ICPC 南京站](https://qoj.ac/contest/2581) 五小时团队 VP
  - 官方难度顺序：`C < K < F/G/I/M < B/E/H/J < A/L < D`
  - 两小时目标：`C、K` 全过，并从 `F/G/I/M` 中兑现至少 2 题
  - 你的主读顺序：`G → I → B → M/L`
- [ ] [2024 ICPC 南京站](https://sua.ac/wiki/2024-icpc-nanjing/) 45 分钟读题排难度 + 三小时选题
  - 只做 `C、I、M`，不追防 AK 题
- [ ] [2023 ICPC 南京站](https://sua.ac/wiki/2023-icpc-nanjing/) 只做专项，不整场 VP

### 数学位必做

- [ ] `2025 G - Bucket Bonanza`：拆掉容量与漏速的对应关系、排序贪心、二分
  - 任务：证明合并等价于删去较小容量和较大漏速
- [ ] `2025 I - Chi Fan`：带概率状态的倒序预算 DP
  - 任务：解释为何必须倒序，而不是机械套期望 DP
- [ ] `2025 B - What, More Kangaroos?`：整数不等式转半平面方向、极角扫描
  - 任务：证明把点沿方向放到充分远处后常数项不再重要
- [ ] `2024 C - Topology`：树拓扑序计数、组合数、前缀和优化转移
  - 任务：独立推出外向树拓扑序公式 `n! / ∏ size[u]`
- [ ] `2024 I - Bingo`：`min-max` 容斥、最大值计数、卷积
  - 任务：本月只要求完整推导和通过；若 NTT 模板不熟，先补模板再写
- [ ] `2023 G - Knapsack`：交换论证、分界点、前缀背包与后缀 Top-k
  - 任务：先证明最优解存在分界点，再开始 DP

### 推荐提高

- [ ] `2025 M - Many Convex Polygons`：计数／几何结构
- [ ] `2025 L - Regional Champion`：欧拉公式、平面划分上界与构造
- [ ] `2024 M - Ordainer of Inexorable Judgment`：凸几何膨胀、切线与周期贡献
- [ ] `2023 C - Primitive Root`：异或不等式把看似数论的问题压到常数检查

## 四、CCPC 长春专项

> 2026 长春正式站命题组尚未公开。下面使用命题来源明确的东北代理样本训练，不声称它们就是长春正式赛题风。

### 整场训练

- [ ] [2026 CCPC 黑龙江省赛](https://qoj.ac/contest/3768) 五小时团队 VP

  - 复盘重点：是否能快速识别构造上界、期望下界和十进制性质

### 数学位题单

- [ ] `2026 黑龙江 C - 圆桌会议`：环排列构造、连续三元组中位数与下界
- [ ] `2026 黑龙江 J - 秋水横渡`：相位同步、均匀偏移与期望下界
- [ ] `2026 黑龙江 B - 最大数码 2`：十进制构造与跨位数字典序细节
- [ ] `2026 黑龙江 E - 乐乐的杏花`：树上距离动态维护；作为数学位的实现补强
